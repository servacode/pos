# تصميم واجهات سيرفا

كل شاشات المشروع مصمّمة بالهوية الزمرّدية (قرار المالك) على لوحة التصميم الحيّة:
https://claude.ai/artifact/B7ZRm38jg61i1oqJ4WdFFS

اللوحة هي المرجع للشكل، والمواصفات في `docs/specs` هي المرجع للسلوك والمحتوى.

- **صفحات اللوحة (17):** النموذج التفاعلي، والهوية البصرية، ثم 15 صفحة للشاشات: التسجيل والبداية، الكاشير، شاشات القطاعات، النادل والمطبخ، إدارة المتجر، جوال صاحب المحل، لوحة المنصة، لوحة الوكيل، وضع المندوب، بوابة المحاسب، المتجر والمنيو والإيصال، صفحات المنصة العامة، المطبوعات، الرسائل الصادرة، الحالات المشتركة.
- **عدد الألواح:** 195 لوحاً للشاشات، وكثير منها يجمع عدة حالات أو خطوات للشاشة نفسها.
- [`screen-inventory.md`](screen-inventory.md): جرد كل لوح، مع مقاسه وما يجب أن يظهر عليه ومصدره في المواصفات.
- [`kit/`](kit/): عدّة الواجهة المشتركة التي بُنيت بها كل الشاشات. تشمل الرموز والألوان (`serva-ui.css` وإضافاته)، و108 أيقونات، والشعار وأيقونة التطبيق، وقالب اللوح. تُلصق كما هي، لذلك هذا المجلد مستثنى من Prettier.
- [`open-questions.md`](open-questions.md): الثغرات والتناقضات التي وجدها المصممون في المواصفات أثناء الرسم. تُحسم في جولة تحديث المواصفات القادمة.
