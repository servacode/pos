# بوت واتساب لرموز التسجيل

برنامج صغير منفصل يرسل رمز التحقق إلى واتساب صاحب الحساب الجديد. يستدعيه خادم سيرفا حين
يكون `OTP_DELIVERY=gateway` (`docs/local-server.md` ← «إرسال الرمز عبر واتساب»). وحين ننتقل
لاحقاً إلى واتساب الرسمي أو SMS، يُستبدل هذا البرنامج وحده، ولا يتغيّر شيء في سيرفا.

**تنبيه:** هذا ربط غير رسمي بواتساب، مثل واتساب ويب. قد يحظر واتساب الرقم. لذلك:

- استعمل **رقماً مخصصاً للبوت** على جوال قديم أو شريحة جديدة، لا رقم المحل ولا رقمك.
- البوت لا يرسل أكثر من 5 رموز في الساعة للرقم الواحد، وينتظر ثانيتين ونصف بين كل رسالتين.

## التشغيل

على الكمبيوتر نفسه الذي عليه الخادم، أو أي كمبيوتر على الشبكة نفسها، ومعه Node.js 22:

```bash
cd tools/whatsapp-otp-bot
npm install
BOT_TOKEN=<سر طويل، 16 حرفاً على الأقل> npm start
```

أول مرة يظهر رمز QR في النافذة. على جوال البوت افتح واتساب ← الإعدادات ← **الأجهزة
المرتبطة** ← **ربط جهاز**، وامسح الرمز. يظهر «✔ WhatsApp linked». يحفظ الربط في المجلد
`auth/`، فلا تمسح الرمز مرة أخرى.

ثم في `deploy/local/.env` على الخادم:

```
SERVA_OTP_DELIVERY=gateway
SERVA_OTP_GATEWAY_URL=http://<عنوان كمبيوتر البوت>:3001/send
SERVA_OTP_GATEWAY_TOKEN=<السر نفسه>
```

وشغّل `pnpm local:up`.

## الفحص

- `http://<العنوان>:3001/health` يجيب `{"linked":true}` حين يكون واتساب مربوطاً.
- إن انقطع الربط من الجوال (تسجيل خروج)، احذف المجلد `auth/` وشغّل البوت من جديد وامسح الرمز.
- اختبارات الجزء الذي يستقبل الطلبات: `node --test server.test.mjs`. تعمل في CI دون تنزيل
  مكتبة واتساب.

## الإعدادات

| المتغير     | المعنى                     | الافتراضي |
| ----------- | -------------------------- | --------- |
| `BOT_TOKEN` | السر الذي يرسله خادم سيرفا | إلزامي    |
| `PORT`      | المنفذ                     | `3001`    |
| `HOST`      | العنوان الذي يستمع عليه    | `0.0.0.0` |
| `AUTH_DIR`  | مجلد حفظ الربط             | `./auth`  |
