# Serva POS

منصة كاشير سحابية باشتراكات (SaaS)، عربية أولاً، تعمل حتى عند انقطاع الإنترنت، وتناسب كل أنواع المحلات: ألبسة، سوبرماركت ومولات، مطاعم، مقاهٍ، صيدليات وغيرها. هدفها أن يستخدمها أي شخص يجيد استخدام الحاسوب، دون محاسب.

> المواصفات الكاملة (الخطة، المنافسون، القطاعات، مساعد واتساب، نموذج المنصة، المستندات، العلاقات، الحسابات المالية، الدورة التشغيلية) في مستند المشروع، وهي المرجع لكل ما يُبنى هنا.

## ما الموجود الآن (المرحلة 0: التأسيس)

- **تسجيل متجر جديد ذاتياً:** يُنشئ المتجر وإعداداته واشتراكه في الباقة المجانية والفرع الرئيسي والجهاز الأول والأدوار الجاهزة وحساب المالك، في عملية واحدة.
- **تسجيل الدخول برقم الجوال:** يقبل الرقم بأي صيغة شائعة (09…، +963…، أرقام عربية)، مع جلسات آمنة تتجدد تلقائياً وتُلغى عند الخروج.
- **عزل بيانات كل متجر داخل قاعدة البيانات نفسها** (Row-Level Security)، مع اختبارات تثبت أن متجراً لا يرى ولا يغيّر بيانات متجر آخر.
- **محرك المال والفواتير:** أعداد صحيحة بأصغر وحدة للعملة، تقريب موحّد، توزيع خصم الفاتورة دون فرق قرش، ضريبة شاملة أو غير شاملة، وتحويل بين الليرة والدولار.
- **واجهة عربية من اليمين لليسار:** إنشاء المتجر، تسجيل الدخول، والصفحة الرئيسية.
- **فحوص آلية مع كل تغيير:** التنسيق، الأخطاء البرمجية، الأنواع، الاختبارات، والبناء.

## البنية

| المجلد          | المحتوى                                                                |
| --------------- | ---------------------------------------------------------------------- |
| `apps/web`      | تطبيق الويب (React + Vite + Tailwind)، عربي RTL                        |
| `apps/api`      | الخادم (Node.js + Fastify)                                             |
| `packages/core` | منطق مشترك: المال والتسعير، الصلاحيات، القطاعات، العملات، عقود الطلبات |
| `packages/db`   | مخطط قاعدة البيانات (PostgreSQL + Drizzle) والترحيلات وطبقة العزل      |

## التشغيل محلياً

المتطلبات: Node.js 22، pnpm 10، PostgreSQL 16 (أو Docker).

```bash
pnpm install
cp .env.example .env
```

قاعدة البيانات: إما `docker compose up -d`، أو على PostgreSQL محلي:

```bash
pnpm db:bootstrap
```

ثم:

```bash
pnpm db:migrate
pnpm db:seed
pnpm dev
```

التطبيق على http://localhost:5173 والخادم على http://localhost:3000.

## الفحوص

```bash
pnpm check
```

اختبارات الخادم تعمل على قاعدة `serva_test` فقط، وترفض العمل على أي قاعدة لا ينتهي اسمها بـ `_test`.

## قاعدة البيانات والأمان

- دوران في PostgreSQL: `serva_owner` يملك الجداول ويشغّل الترحيلات، و`serva_app` يستخدمه الخادم ويخضع لعزل المتاجر.
- كل جدول للمتجر يحمل `tenant_id`، والخادم يحدد المتجر لكل عملية عبر `withTenant()`.
- الروابط بين جداول المتجر مركّبة مع `tenant_id`، فلا يمكن ربط سجل بسجل متجر آخر حتى مع معرفة معرّفه.
- كلمات المرور مشفّرة بـ argon2id، ورموز التجديد تُخزَّن مجزّأة فقط.
